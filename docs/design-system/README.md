# keepbook design-system preview bundle

Self-contained HTML preview pages for keepbook's design tokens and components,
intended for upload to a claude.ai Design System project where each page renders
standalone inside an iframe under a strict CSP (no external requests). Every page
is fully inline: it embeds the **entire** contents of
`crates/keepbook-dioxus/assets/styles.css` verbatim in a `<style>` tag (the
single source of truth for tokens and component classes), plus a small
page-specific `<style>` for preview scaffolding (swatch grids, theme columns)
only. Body markup mirrors the real app DOM using the same class names the Dioxus
`rsx!` emits (see `crates/keepbook-dioxus/src/views/*.rs`). Because the tokens are
defined on `:root`, pages that show both themes re-emit the two token blocks —
extracted directly from `styles.css` — additionally scoped to
`[data-theme-scope="fern"]` and `[data-theme-scope="dark"]` so both themes render
side by side in one document. The bundle is generated by a script that reads
`styles.css` at build time (rather than hand-copying fragments that could drift);
regenerate it whenever `styles.css` changes. Each file's first line is a
`<!-- @dsCard group="…" name="…" -->` marker consumed by the Design System
importer. Pages: `colors.html`, `typography.html` (Foundations);
`buttons.html`, `panels.html`, `badges.html`, `forms.html` (Components);
`charts.html` (Charts).

## Design documents

- [Interaction states](interaction-states.md) defines loading, in-flight,
  success, failure, cancellation, and control-locking behavior for every app
  surface.
- [Design tokens](../design-tokens.md) defines the semantic visual tokens used
  by the app and preview bundle.
